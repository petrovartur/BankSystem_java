Bank Management System - это консольное Java-приложение для управления банковскими клиентами, счетами и транзакциями.

Функционал

* Добавление клиентов
* Открытие банковских счетов
* Пополнение счета
* Снятие средств
* Перевод между счетами
* Просмотр баланса счета
* История транзакций
* Аналитика по клиентам и счетам


Инструкция по запуску:

1. Открыть проект в IntelliJ IDEA
2. Найти файл Main.java и запустить его
3. Для использование нужного элемента пропишите цифру нужного действия (0-7) и нажмите enter


Меню программы состоит из следующих элементов:

===== Bank =====
1. Add client - Добавить клиента
2. Open account - Открыть счёт
3. Op Up Balance - Пополнить счёт
4. Withdraw money - Снять деньги
6. Check balance - Показать баланс
7. Transaction history - История транзакций
0. Exit - Выход
